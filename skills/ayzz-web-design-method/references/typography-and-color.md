# Typography & Color — the ayzz system

The Colors & Fonts deck (step 3 of the method) is where the look is won. This file is the concrete reference for it.

## Typography

### The core move: tall condensed display + elegant serif
His type taste centers on **tall, condensed, heavy display fonts** for impact, paired with an **elegant high-contrast serif** when a brand needs luxury softness. He uses type *big* — headlines and wordmarks are the largest thing on the page.

### Fonts he explicitly champions
From his "Tall fonts I'd use in every design" reel and project builds:

| Font | Class | Use it for |
|---|---|---|
| **Druk / Druk Heavy** | Tall condensed display | Loud, fashion-editorial headlines and wordmarks |
| **Theater Cond** | Tall condensed display | Poster-style hero type, big statements |
| **Moho Cond** | Tall condensed display | Same family of impact; bold section headers |
| **PLAT / Plat Extended** | Wide extended display | Luxury wordmarks (used for the VELOUR candle brand) |
| **Pandory** | High-contrast elegant serif | Quiet-luxury brands, beauty, editorial softness |

He also runs a recurring **"Fav Free Fonts" series** (Part 1, 2, … 5+) — the through-line is the same taste: characterful display faces and refined serifs, never the default system stack.

### Pairing logic
- **One display face does the shouting**, one neutral or serif face does the reading. Don't mix two loud display fonts.
- **Match the face to the mood**: condensed-heavy for bold/impactful brands; extended for luxury; high-contrast serif for soft/premium/beauty.
- **Set the wordmark huge** — treat the brand name as a graphic element (see imagery-and-layout).
- **Mix weights and styles within a headline** for editorial rhythm: e.g., a bold sans "Skincare" over an italic serif "essentials." 

### Banned defaults (aligns with Karim's standing rule)
Do **not** auto-reach for Cormorant / Outfit / JetBrains Mono / Noto Kufi as the "premium" default, and don't decorate code with `// 01 — THE MISSION` comment-labels. Pick a characterful face that serves *this* brief. The whole point of his Colors & Fonts step is a deliberate, mood-driven choice — not an autopilot pairing.

## Color

### The principle: one tonal, mood-matched palette
Each site uses a **tight, tonal palette pulled straight from the brand's mood and product** — not a generic UI palette. Strong color-blocking (full sections in one rich color) is a recurring device. The hero often goes **dark and cinematic**; product/utility sections go **clean off-white** for contrast and calm.

### Mood → palette table (from his actual projects)

| Brand / mood | Palette | Notes |
|---|---|---|
| **VELOUR** — luxury candle, "warm, atmospheric, moody" | Deep burgundy / oxblood + cream + black, warm orange candle-glow accents | Dark cinematic hero; cream "Best Sellers" section |
| **Axirya** — skincare, "powerful, pure, gentle" | Soft pink → peach gradients + lilac, near-white | Glowy, luminous, feminine; gradient backgrounds |
| Skincare "**Galaxy**" concept | Purple / magenta + cosmic nebula imagery | "Radical transparency. Hide nothing." cosmic editorial |
| **CALMM** — gut-health supplement | Cream / off-white + natural green + soft sky blue | Clean, healthy, nature; floating grass-island hero |
| **Fresh Beans / Lounge** — coffee, "immersive & playful" | Warm orange / terracotta + cream + dark roast brown | Cozy, energetic; liquid-coffee motion hero |

### How to build a palette for a new brand
1. Name the mood (step 1) in 3 adjectives.
2. Pull the **dominant tone from the product/packaging** (candle wax → burgundy; coffee → roast brown; supplement → green).
3. Set a **rich dark or saturated hero color** + a **clean off-white** for calm sections + **1 warm accent** (often a glow).
4. Keep it to ~3 colors + neutrals. Tonal, not rainbow.

## Putting the deck together
A Colors & Fonts frame, in his style, contains:
- A giant `Aa` specimen in the chosen display font (+ the serif/secondary).
- The font names labeled.
- 3–5 color swatches with the dominant, the off-white, and the accent.
- Optionally the wordmark set in the display font, to test it at hero scale.

Lock this, screenshot it, and design every section to it.
