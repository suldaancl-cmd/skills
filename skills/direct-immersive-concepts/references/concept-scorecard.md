# Immersive concept scorecard

Score each dimension 1–5 and add one sentence of evidence. Do not use half-points.

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Brand inevitability | Could fit any brand | Connects to an attribute | Could only belong to this brand |
| Originality | Copies a known site | Familiar mechanism, new styling | New mechanism or synthesis |
| Emotional clarity | No arc | Some progression | Deliberate, legible transformation |
| Content usefulness | Effects obscure content | Content survives | Interaction increases understanding |
| Interaction potential | Decorative hover only | Several useful states | User action embodies the idea |
| Visual-system potential | Moodboard only | Some reusable tokens | Generates type, color, space, and imagery rules |
| Technical feasibility | Depends on unknown R&D | Feasible with prototypes | Proven path within team and budget |
| Mobile/reduced-motion | Collapses or disappears | Simplified but incomplete | Equivalent meaning with lighter behavior |
| Performance risk | Blocks first paint or overloads GPU | Manageable with downgrades | Progressive, lazy, measurable |
| Conversion clarity | CTA is lost | CTA exists | Narrative naturally releases into action |

## Decision

- Reject below **35/50**.
- Reject if Brand inevitability is below **4**.
- Reject if Content usefulness or Mobile/reduced-motion is below **3**.
- If two routes tie, choose the one with fewer dependencies and a clearer signature moment.

## Anti-copy test

Remove the brand name and screenshots. If a reviewer can immediately name the reference site being copied, redesign the mechanism.
