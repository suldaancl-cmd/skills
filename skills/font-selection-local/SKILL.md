# Font Selection Local

Use these local references:

- `../awesome-fonts-local/references/awesome-fonts.md`
- `../google-fonts-local/references/google-fonts-family-index.md`
- `../nerd-fonts-local/references/nerd-fonts-index.md`

Workflow:

1. Identify roles: display, body, UI label, code, numeric/data, accent, and fallback.
2. Match the font to product tone, density, language/script coverage, and rendering environment.
3. Prefer fewer families and more weights only when the design actually needs them.
4. Include CSS fallbacks and licensing/source notes when making implementation recommendations.
