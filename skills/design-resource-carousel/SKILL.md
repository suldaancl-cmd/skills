# Design-Resource Carousel Formula

A whole class of design creators grows fast on one content type: the **resource carousel** — color combos, font pairings, or tool lists, packaged so designers *save* and *share* them. It's the static-carousel sibling of the [ayzz-design-reel-formula](../ayzz-design-reel-formula/SKILL.md) video play, and it runs the same funnel: free value → saves/comments → DMs → followers → service/product sales.

This skill is the reusable recipe for producing those carousels.

## Why this format wins
- **"Save" is the strongest carousel ranking signal**, and resource content is inherently save-worthy ("I'll need these colors later"). Every slide is designed to be screenshotted and reused.
- **Comment-to-DM** manufactures comments (the second-strongest signal) *and* builds a warm DM list.
- **Series** ("Part 2", "Part 5") trains the audience to follow and wait for more.
- Designers are a high-intent niche audience that converts to clients.

## The slide structure

### 1. Cover slide — the promise
One bold line + (optionally) a "Part N". Make the title the biggest thing; add a cinematic or branded background and your handle as a watermark. Cover patterns that work:
- **Save-bait:** "Save these colors for your next project"
- **Authority/scarcity:** "Tools I can't work without as a designer"
- **Premium promise:** "Premium color combos for your brand"
- **Series tag:** add "Part 2" to signal there's more and pull a follow.

### 2. Resource slides — one item per slide (the meat)
This is what gets saved, so make the reusable data legible:

- **Color combo:** present each color as a **card showing the name + CMYK + RGB + HEX**. The strong execution (dyslove.design) floats a **frosted-glass card over a cinematic, tone-matched photo** (e.g. "Carbon · #171717" over a dark coal image) — far more premium than flat swatches. Typically **2 curated pairs per post**, named (e.g. "Carbon + Lime", "Onyx + Candy Blue").
- **Tool:** a clean **screenshot of the tool's website** + the **name/URL** + one line on what it does. (bob_graphix: mockups-design.com, colorhunt.co, unblast.com.)
- **Font:** the **font name** + a large **specimen** + a short style label (e.g. "display", "monospaced").

### 3. CTA / outro slide
Close with the asks, in priority order: **Save** → **Comment [keyword]** (the DM gate) → **Follow for more**. Repeat the handle/watermark.

## The CTA mechanics (the engine)
- **Comment-to-DM gate** — the highest-leverage move: *"Comment PROMPT to create your own color combo"* / *"Comment [keyword] and I'll send it to your DM."* Pick a short keyword tied to the payoff.
- **Explicit "Save this for your next project"** — directly asks for the top signal.
- **Follow nudge** — "Follow @handle for more."

Use all three, but the comment-to-DM is the one that compounds (comments + lead list).

## Caption template
```
[Comment-keyword CTA or "Save these" — first line, visible before "…more"]

[What's inside — name the items]
"Two curated color pairs for branding, UI, and digital design:
Carbon + Lime / Onyx + Candy Blue."

[Save instruction + handle]
"Save for your next project. @yourhandle"

[Niche hashtags]
#colorpalette #colorcombo #colorinspo #designresources #graphicdesign
```
- **Lead with the CTA** so it shows unexpanded.
- **Name the items** in the caption (searchable + sells the click).
- **Niche hashtags**, not broad ones.
- **Arabic-first for MENA reach:** creators like bob_graphix write the whole caption in Arabic/Egyptian dialect. For Karim's audience, write the caption in Arabic and keep tool names/URLs and hex codes in inline English (per the bilingual layout rule).

## Slide visual treatment
- **One consistent template** across all slides (same grid, type, watermark) = a recognizable, professional set.
- **Big, phone-legible type.** Assume it's viewed at thumbnail size first.
- **Show the values** for colors (CMYK/RGB/HEX) — that's the reason people save.
- **Elevate the background** — cinematic/tonal photos or subtle gradients beat plain white; the glass-card-over-photo look reads as premium.
- **Watermark every slide** with your handle so reposts credit back to you.

## How to produce one with this skill
1. Pick the **resource type** (colors / fonts / tools) and a **count** (2 combos, 3 tools, 5 fonts).
2. Write a **cover line** (save-bait / authority / promise) + decide if it's a "Part N" series.
3. Build one **resource slide per item** with the reusable data shown clearly.
4. Add the **CTA/outro slide** (save → comment-keyword → follow).
5. Write the **caption** from the template (Arabic-first for MENA).
6. Keep a **consistent template + watermark** throughout.

Tools to execute the visuals: `aistudiotoday-carousel`, `canvas-design`, `banner-design`, or `imagegen` for backgrounds; `color-system` / `ui-ux-pro-max` to source palettes; `font-pairing-local` for fonts.
