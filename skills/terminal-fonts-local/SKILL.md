# Terminal Fonts Local

Use these local references:

- `../nerd-fonts-local/references/nerd-fonts-index.md`
- `../nerd-fonts-local/references/fonts.json`

Workflow:

1. Check whether the user needs a terminal/editor font or app UI font.
2. Recommend a Nerd Font Mono variant for terminal alignment.
3. For missing glyphs, verify the terminal profile is using the installed Nerd Font, not just a system mono font.
4. Avoid cloning the full Nerd Fonts repo for installation; use release archives or platform package managers unless contributing.
