# Programming Fonts Local

Use these local references:

- `../nerd-fonts-local/references/nerd-fonts-index.md`
- `../awesome-fonts-local/references/awesome-fonts.md`

Workflow:

1. Decide whether the context is editor, terminal, code block, dashboard numbers, or marketing code sample.
2. Prefer monospaced fonts with clear `0/O`, `1/l/I`, punctuation, and strong small-size rendering.
3. Use Nerd Fonts when terminal icons, Powerline, devicons, or prompt glyphs are required.
4. Mention ligature tradeoffs when relevant.
5. Provide a CSS or editor/terminal font stack when implementation is requested.
