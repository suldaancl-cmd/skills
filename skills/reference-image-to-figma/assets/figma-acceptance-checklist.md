# Figma Acceptance Checklist

## Reference

- [ ] Original reference preserved and locked.
- [ ] Viewer/editor chrome excluded from the product frame.
- [ ] Target viewport, platform, locale, and source hierarchy recorded.
- [ ] Generated or uncertain text replaced with verified live content.

## Structure

- [ ] No full-screen raster is acting as the final interface.
- [ ] Semantic UI uses live text and native Figma nodes.
- [ ] Repeated UI uses components and meaningful variants.
- [ ] Stacks, lists, controls, and navigation use auto layout.
- [ ] Variables are bound to actual nodes.
- [ ] Layer names describe product roles.
- [ ] Background art and interactive UI are separated.

## States and locales

- [ ] Required default, pressed, focused, disabled, loading, error, and success states exist.
- [ ] Arabic RTL and English LTR are verified.
- [ ] Directional icons mirror only when semantically correct.
- [ ] Long copy and text scaling do not break the layout.

## Fidelity and handoff

- [ ] Figma render compared with the reference at matching dimensions.
- [ ] Blocking and major deltas fixed or explicitly approved.
- [ ] Assets have rights/source/export metadata.
- [ ] Component, variable, and node inventory delivered.
- [ ] Motion candidates and runtime owners documented.
