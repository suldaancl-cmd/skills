# Awesome DESIGN.md Local

Bundled source: `references/design-md`
Original clone: `C:\tmp\awesome-design-md`

Use this skill when a task asks to make an interface look like a known product, brand, or design style from the bundled DESIGN.md library.

Workflow:

1. Pick the closest brand folder under `references/design-md`.
2. Read that folder's `DESIGN.md`; use `README.md` only for extra context.
3. Extract concrete tokens: typography, colors, spacing, surfaces, imagery, motion, and layout rules.
4. Apply the style to the user's actual product instead of copying brand trademarks or content verbatim.
5. For frontend work, verify responsive layout and text fit after implementation.

When the user names a specific brand, prefer the matching `design-md-*` wrapper skill if it exists.
