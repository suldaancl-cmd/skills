# Figma workflows

A Figma MCP server is available in this environment (`mcp__9f8892a0-...`). It exposes tools for reading designs, variables, screenshots, code connect, and generating design-system rules. Use it rather than asking the user to export things manually.

## Available Figma MCP tools

- `mcp__9f8892a0-...__get_design_context` — fetch the current Figma selection's structured context (layers, tokens, components)
- `mcp__9f8892a0-...__get_screenshot` — screenshot the current selection or a specific node
- `mcp__9f8892a0-...__get_metadata` — hierarchical metadata for a design
- `mcp__9f8892a0-...__get_variable_defs` — design variables (tokens) defined in the file
- `mcp__9f8892a0-...__search_design_system` — search the connected design system for components
- `mcp__9f8892a0-...__get_code_connect_suggestions` — suggestions for mapping Figma components to code
- `mcp__9f8892a0-...__add_code_connect_map` / `get_code_connect_map` / `send_code_connect_mappings` — manage component-to-code mappings
- `mcp__9f8892a0-...__get_context_for_code_connect` — context for writing a Code Connect entry
- `mcp__9f8892a0-...__create_design_system_rules` — generate rules for maintaining design system consistency
- `mcp__9f8892a0-...__create_new_file` — create a Figma file
- `mcp__9f8892a0-...__generate_diagram` — generate a diagram (useful for IA/flows)
- `mcp__9f8892a0-...__get_figjam` — read a FigJam board
- `mcp__9f8892a0-...__use_figma` / `mcp__9f8892a0-...__whoami` — environment checks

These must be loaded via `ToolSearch` before first use — they're deferred tools. Example: `ToolSearch("select:mcp__9f8892a0-ddbc-4d23-ae64-af4468a9dab2__get_design_context")`.

## Common workflows

### A. Figma → code (pixel-perfect implementation)

1. **Get context for the selected frame**
   - `get_design_context` returns structure, text, colors, spacing, variables used.
   - `get_screenshot` gives you the visual target.
2. **Pull tokens** — `get_variable_defs` exports the design variables. Convert to CSS variables or a tokens.json.
3. **Match components** — `search_design_system` to find existing code components that match. If the design system has Code Connect mappings, `get_code_connect_map` returns them.
4. **Implement** — use the tokens, follow the existing design-system conventions in the codebase. Don't invent new patterns when existing ones match.
5. **Handoff back** — if you added a new component that doesn't exist in Figma's Code Connect yet, use `add_code_connect_map` + `send_code_connect_mappings` to register it.

### B. Code → Figma (reverse-engineering)

When a codebase has no Figma source of truth:
1. Screenshot or DOM-scrape each unique component.
2. Generate a Figma file with `create_new_file`.
3. Use `create_design_system_rules` to establish token patterns.
4. Manually or scripted-rebuild the component library. Not fully automated — this is still craft work.

### C. Design system sync

1. `get_variable_defs` to export all variables as design tokens.
2. Generate a `tokens.json` (Style Dictionary format is the standard).
3. In your code repo, consume that tokens.json via a build step to produce:
   - `tokens.css` (CSS variables)
   - `tokens.ts` (TS types)
   - Tailwind theme extension
4. Commit tokens to your repo alongside the build output. Treat Figma as the source of truth; never hand-edit the output files.

### D. Flow diagrams & IA

Use `generate_diagram` or `get_figjam` for:
- User flows / journey maps
- Information architecture diagrams
- State machines
- Sitemaps

For IA-heavy work, the Figma diagramming tools often beat Mermaid in exports the team can collaborate on.

## Design tokens — the bridge

The moment a design system grows past 10 components, tokens become essential. Figma Variables → tokens.json → code is the standard pipeline.

**Figma Variables structure:**
- Primitive collections: `color/neutral-100`, `color/neutral-200`, …
- Semantic aliases: `color/text-primary` → references `color/neutral-900`
- Component tokens: `color/button-bg` → references `color/brand-500`
- Mode switching: light / dark / high-contrast as Figma modes

**In code:**
```css
:root { --color-text-primary: var(--color-neutral-900); }
[data-theme="dark"] { --color-text-primary: var(--color-neutral-100); }
```

Automation: `figma-tokens` plugin + Style Dictionary, or Tokens Studio + direct sync.

## Code Connect — link Figma components to code

The pay-off for Code Connect setup: designers see the actual React/Vue component's props in Figma Dev Mode; engineers get autogenerated code snippets that match existing components.

Setup:
1. `figma connect create` (Figma CLI) — scaffolds a Code Connect file for a component.
2. Map props: Figma variants → React/Vue props.
3. `send_code_connect_mappings` or `figma connect publish` to push.
4. In Dev Mode, the component now shows real code, not auto-generated guesses.

This matters most for teams shipping weekly. A one-off landing page doesn't need Code Connect.

## Common Figma → code mistakes

- **Hardcoding pixel values instead of tokens.** Design variables exist; use them.
- **Copying spacing from Figma rulers directly without checking the spacing scale.** Figma shows the actual gap; the design system usually has a defined step. Round to the nearest token.
- **Ignoring auto-layout direction.** Figma's auto-layout maps cleanly to `display: flex`; the gap, padding, and direction are already decided.
- **Rebuilding icons by hand.** Export SVGs from Figma, optimize with SVGO.
- **Missing states.** Figma usually shows rest state; hover, focus, active, disabled, loading all need their own design or a reasonable extrapolation. Ask the designer if not shown.
- **Breakpoints mismatch.** Figma frames are often 1440, 834, 390. Map to code breakpoints explicitly: `1280px+` → 1440 design, `768px+` → 834, `<768px` → 390.

## When Figma isn't available

- **User has no Figma access or no design file** — run the full design pipeline (research → aesthetics → design system → implementation). You are the designer.
- **User provides a screenshot** — reverse-engineer the tokens (read the image with Vision), extract colors, estimate type scale, implement.
- **User provides a competitor URL** — fetch it with browser tools, study the tokens, then design something distinctive (not a copy).

## The principle

Figma is a source of truth, not a prison. When the design has obvious issues (bad contrast, too tight spacing, impossible responsive), flag them and propose fixes. Ship a better design, not a pixel-perfect flawed one.
