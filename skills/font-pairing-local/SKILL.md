# Font Pairing Local

Use these local references:

- `../google-fonts-local/references/google-fonts-family-index.md`
- `../awesome-fonts-local/references/awesome-fonts.md`

Workflow:

1. Pick one anchor font first: display, body, or mono.
2. Pair by contrast: serif/sans, geometric/humanist, formal/utility, condensed/open, or neutral/expressive.
3. Keep x-height, stroke contrast, and spacing compatible for UI text.
4. For web apps, choose families with reliable weights and language coverage.
5. Return a small type scale and fallback stack, not just font names.
