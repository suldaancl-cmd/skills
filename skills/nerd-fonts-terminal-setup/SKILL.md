Use these local references:

Workflow:

1. Pick a patched Mono family that matches the user's preferred coding font.
2. Use release archives or platform package managers for install guidance.
3. After installation, configure the terminal/editor profile to use the Nerd Font family.
4. For tofu boxes or missing symbols, check font selection, fallback order, and prompt theme glyphs.
