# Java Design Patterns Local

Original clone: `C:\tmp\java-design-patterns`
Pattern index: `references/pattern-index.md`

Use this skill when a task asks for Java design patterns, architecture patterns, enterprise patterns, concurrency patterns, microservice patterns, or pattern-driven refactoring.

Workflow:

1. Search `references/pattern-index.md` for the closest pattern name.
2. Read that pattern folder's `README.md` before explaining or implementing it.
3. Inspect Java source under the pattern folder when code-level accuracy matters.
4. Prefer the simplest pattern that fits the problem; do not force a pattern where plain code is clearer.
5. When implementing in an existing project, match local style and tests rather than copying examples wholesale.

When the user names a specific pattern, prefer the matching `jdp-*` wrapper skill if it exists.
