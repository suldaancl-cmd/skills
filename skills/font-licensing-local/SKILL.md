# Font Licensing Local

Use these local references:

- `../google-fonts-local/references/google-fonts-family-index.md`
- `../nerd-fonts-local/references/fonts.json`
- `../font-awesome-local/references/metadata/icons.json`

Workflow:

1. Treat repository license buckets as a starting point, not legal advice.
2. For Google Fonts, check the family path bucket: `ofl`, `apache`, or `ufl`.
3. For Nerd Fonts, check RFN and original license metadata before renaming or redistributing.
4. For Font Awesome, distinguish free/pro assets and confirm style availability.
5. Recommend self-hosting only when the license and product constraints allow it.
