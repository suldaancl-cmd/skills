## When To Use

Use this skill when a task asks for:

- Web, desktop, or mobile prototypes.
- Landing pages, dashboards, posters, cards, decks, documents, or social assets.
- Design-system-aware UI generation.
- Visual critique, refinement, or creative direction.
- Open Design workflow, plugin, template, or skill adaptation.

## Workflow

1. Inspect the relevant local Open Design skill or template before designing.
2. Reuse the closest existing pattern instead of inventing a new workflow.
3. Favor concrete artifacts over prose-only design advice.
4. Apply a self-critique pass for visual hierarchy, spacing, typography, responsiveness, and production readiness.
5. Keep output portable: HTML, CSS, Markdown, PPTX, PDF, image, or video depending on the requested artifact.

## Notes

The upstream repository contains many standalone `SKILL.md` files. Do not copy them wholesale into the root skills directory without checking for name collisions with existing local skills.
